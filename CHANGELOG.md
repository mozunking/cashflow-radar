# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-18

### Added
- Initial MVP release
- IForest, LOF, Graph anomaly detection models
- Dual-engine fusion (rules + algorithm)
- SHAP/LIME explainability
- 4-page Streamlit management console
- PostgreSQL persistence layer
- Redis-based degradation management
- MLflow model versioning
-等国密算法支持 (SM2/SM3/SM4)
- 等保2.0三级合规

### Features
- T+1 batch anomaly detection
- Real-time anomaly explanation
- Human feedback loop for model improvement
- Hot-swap model deployment
- One-click rollback
- 36-month audit log retention
