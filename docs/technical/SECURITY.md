# 安全机制

---

## 1. 鉴权与访问控制

### JWT-RS256鉴权流程

```
1. 用户登录 → 输入用户名/密码
2. 服务端验证 → 生成RS256签名JWT（15分钟有效期）
3. 每次请求 → Header携带Authorization: Bearer <token>
4. API网关验证JWT → 提取角色 → 检查权限
```

### 角色权限

| 角色 | 权限范围 |
|------|---------|
| analyst | 监控仪表盘、预警复核 |
| supervisor | analyst + 复核审批、审计日志 |
| scientist | analyst + 模型训练 |
| operator | scientist + 模型发布/下线 |
| admin | 全部功能 |
| audit | 监控仪表盘、审计日志（只读） |

## 2. 国密算法适配

| 场景 | 算法 | 实现 |
|------|------|------|
| API签名 | SM2-with-SM3 | gmssl |
| 敏感数据加密 | SM4-GCM | gmssl |
| 模型文件完整性 | SM3 | gmssl |
| TLS握手 | SM2 | 需要国密SSL套件 |

## 3. 数据脱敏规则

| 字段 | 脱敏规则 | 示例 |
|------|---------|------|
| 银行账号 | 保留前4后4位 | 6228\*\*\*\*1234 |
| 对手名称 | 保留前2字 | 中石\*\* |
| 身份证号 | 保留前3后4位 | 110\*\*\*\*\*\*\*\*\*1234 |
| 金额 | 取整到万 | 约123万 |

---

## 4. 审计日志要求

- **不可篡改**：写入后不可UPDATE/DELETE
- **36个月留存**：合规要求
- **全量记录**：所有写操作
- **字段**：operator, action, target_type, target_id, details, ip_address, trace_id
