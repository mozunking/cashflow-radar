## 一、业务需求

### 1.1 业务背景

企业资金风控面临以下挑战：
- **规则引擎盲区**：只能检测已知模式，隐性异常漏报
- **预警量大**：有效预警少，风控分析师疲于应付
- **算法黑箱**：无法解释决策过程，审计合规困难
- **模型难更新**：版本发布风险高，缺乏标准化流程

### 1.2 业务目标

| 目标 | 衡量指标 | 首期目标 |
|------|---------|---------|
| 算法独立检出数 | ≥5条/周（算法检出且规则未命中） | 首期12周达到 |
| 误报率 | <30% | 验证期末达到 |
| MTTR | <30分钟 | 降级场景下 |
| 审计追溯成功率 | 100% | 全量覆盖 |

### 3.2 数据质量要求

| 校验类别 | 校验项 | 规则 | 不通过处理 |
|---------|--------|------|-----------|
| 完整性 | 必填字段空值率 | >5% | 阻断+告警 |
| 完整性 | 记录数波动 | 与近7日均值偏差>30% | 阻断+告警 |
| 一致性 | 金额字段符号 | 余额为负或交易金额≤0 | 告警+标记异常行 |
| 时效性 | 数据批次日期 | 非最新T+1批次 | 阻断+告警 |
| 分布 | 关键字段均值偏移 | 与近30日均值偏差>2σ | 告警+记录漂移 |
