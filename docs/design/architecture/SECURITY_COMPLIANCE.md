# 安全与合规

**文档编号**：CAD-DS-V10 | **版本**：10.0 | **日期**：2026-05-18

---

## 6.1 STRIDE威胁分析

| 威胁 | 类型 | 风险 | 缓解措施 |
|------|------|------|---------|
| 窃取模型文件 | 信息泄露 | 高 | SM4加密存储，MinIO服务端加密 |
| 伪造API调用 | 伪造 | 高 | JWT-RS256非对称签名，15分钟过期 |
| 注入恶意训练数据 | 篡改 | 高 | 数据质量校验+审批流+版本冻结 |
| 越权发布模型 | 提权 | 高 | 双人复核+审计日志不可篡改 |
| 逆向模型权重 | 信息泄露 | 中 | API仅输出分数，不输出权重 |
| DDoS | 拒绝服务 | 中 | Nginx限流+Redis令牌桶+熔断降级 |
| 中间人攻击 | 窃听 | 中 | TLS1.3强制开启 |

## 6.2 国密算法适配

| 场景 | 国密替代 | 说明 |
|------|---------|------|
| API签名 | SM2-with-SM3 | JWT签名 |
| 数据加密 | SM4-GCM | 敏感字段存储 |
| 哈希校验 | SM3 | 模型文件完整性 |
| 密钥协商 | SM2 | TLS握手（需国密SSL套件） |

## 6.4 等保2.0三级映射

| 等保要求 | 本方案措施 | 验证证据 |
|---------|-----------|---------|
| 身份鉴别 | JWT+RBAC，密码复杂度，登录失败锁定 | 审计日志 |
| 访问控制 | 菜单级权限，API级鉴权，双人复核 | 权限矩阵 |
| 安全审计 | 全量操作日志，36个月留存，防篡改 | 审计表 |
| 数据完整性 | 模型文件SM3校验，传输TLS1.3 | 校验和记录 |
| 数据保密性 | 敏感字段SM4加密 | 加密配置 |
| 备份恢复 | 每日全量+WAL，异地冷备 | 备份脚本 |

## 6.5 安全监控指标

| 指标 | 告警阈值 | 级别 | 动作 |
|------|---------|------|------|
| 鉴权失败次数>10次/分钟 | 10 | 红色 | 锁定账户+告警 |
| 异常API调用>50次/分钟 | 50 | 黄色 | 限流+告警 |
| 敏感数据访问超权限 | 1 | 红色 | 告警+审计 |
