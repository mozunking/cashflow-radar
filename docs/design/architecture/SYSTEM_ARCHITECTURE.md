## 2.3 模块边界与并行开发映射

每个模块独立仓库、独立API契约、独立测试，支持多团队并行开发：

| 模块 | 仓库 | 负责 | 对外接口 | 依赖 |
|------|------|------|---------|------|
| Core·数据质量校验 | `cad-data-quality` | 数据工程师 | `DataQualityChecker` | 中台宽表 |
| Core·特征工厂 | `cad-feature-engine` | 数据工程师 | `FeatureFactory` | 数据质量校验 |
| Core·模型池 | `cad-model-pool` | 数据科学家 | `ModelPool` | 特征工厂 |
| Core·融合引擎 | `cad-fusion-engine` | 数据科学家 | `FusionEngine` | 模型池+规则引擎 |
| Core·解释引擎 | `cad-explainer` | 数据科学家 | `ExplainerEngine` | 模型池+特征工厂 |
| Core·降级管理 | `cad-degradation` | 后端开发 | `DegradationManager` | Redis |
| Service全部 | `cad-service` | 后端开发 | REST API | Core全部 |
| Console全部 | `cad-console` | 前端开发 | Streamlit Pages | Service REST API |
| Infra | `cad-infra` | 运维工程师 | Docker Compose | 全部 |

**并行开发时间线**：

```
Week 1-2:  [数据工程师]环境搭建+数据探查+质量校验  [架构师]接口契约+技术选型冻结
Week 3-4:  [数据工程师]特征工厂    [数据科学家]模型开发   [后端]API框架  [前端]原型
Week 5-6:  [数据科学家]模型调优   [后端]融合+解释+降级   [前端]4页面开发
Week 7-8:  [全队]集成联调+契约测试   [运维]CI/CD+监控+部署
Week 9-10: [测试]全量测试+回测+混沌   [运维]灰度环境
Week 11-12:[全队]灰度运行+验收+上线
```

## 2.4 SLI/SLO/SLA

| 类别 | SLI | SLO | SLA |
|------|-----|-----|-----|
| 可用性 | 服务正常运行比例 | 99.9% | 99.5% |
| 延迟 | P99批量检测响应 | <5分钟(10万条) | <10分钟 |
| 延迟 | P99解释响应 | <2秒 | <5秒 |
| 准确性 | F1-score(有标注后) | >0.75 | >0.65 |
| 漂移 | PSI超阈值特征比例 | <5% | <10% |
| 降级 | 自动降级切换时间 | <30秒 | <60秒 |
